# Install ChatGPT/Codex MATMA JavaScript skill

Copy this entire folder to `<consumer>/.agents/skills/matma-js-chatgpt/` for Codex environments that recognize local skills. The `agents/openai.yaml` is optional display metadata. For ChatGPT web, attach these files as Project/Work instructions or use a supported skill upload; a local folder alone does not activate the skill. Install MATMA and Vitest in the consuming repo separately.
